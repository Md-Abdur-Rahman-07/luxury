# Self-hosted typography

Downloaded from the official Google Fonts CSS API on 2026-11-20. These are the Latin WOFF2 subsets and are served locally; visitors do not need to contact Google Fonts.

- **Cormorant Garamond, normal:** `cormorant-garamond-latin.woff2`, requested weights 400 and 500. [Font source](https://fonts.gstatic.com/s/cormorantgaramond/v21/co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtK.woff2)
- **Cormorant Garamond, italic:** `cormorant-garamond-italic-latin.woff2`, requested weight 400. [Font source](https://fonts.gstatic.com/s/cormorantgaramond/v21/co3smX5slCNuHLi8bLeY9MK7whWMhyjYrGFEsdtdc62E6zd58jD-iNM8.woff2)
- **Manrope, normal:** `manrope-latin.woff2`, requested weights 400, 500, and 600. [Font source](https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2)

Both families use the **SIL Open Font License 1.1**. Full license texts are included in `Cormorant-Garamond-OFL.txt` and `Manrope-OFL.txt`, obtained from the [official Google Fonts repository](https://github.com/google/fonts/tree/main/ofl). Keep these notices with redistributed font files.
